# Cubo Sans

Static instances of **Google Sans Flex** (SIL Open Font License 1.1, see `OFL.txt`), generated with fontTools
`varLib.instancer` and subset to Latin. They are renamed "Cubo Sans" because "Google Sans" is a Google trademark
that modified versions may not carry; this app is not affiliated with Google.

| CuboSans-Medium.ttf | 500 | 18 |
| CuboSans-Bold.ttf | 700 | 18 |
| CuboSansDisplay-Regular.ttf | 400 | 36 |
| CuboSansDisplay-Medium.ttf | 500 | 36 |
